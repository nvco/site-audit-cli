# site-audit-cli

A CLI tool that audits websites for accessibility, privacy compliance, cookie hygiene, security headers, SSL/TLS, and broken links. Produces markdown, HTML, and JSON reports per run; PDF available opt-in.

---

## Quick start

**Requirements:** Node.js 20+

```bash
git clone https://github.com/nvco/site-audit-cli.git
cd site-audit-cli
npm install
npx playwright install chromium

# Edit a config profile to point at your site, then run:
node dist/index.js config/full.json

# Or just run with no argument — defaults to config/full.json
node dist/index.js
```

Reports are written to `reports/YYYYMMDD-HHmmss/` and named `{domain}-{timestamp}.{ext}` (e.g. `nvco-github-20260519-120212.html`).

---

## Config profiles

Three ready-to-use profiles live in the `config/` folder. Edit the `urls` field and run.

| Profile | Audience | Modules |
|---|---|---|
| `config/sdet.json` | CI/CD pipelines, regression testing | Security headers, broken links, cookies, SSL/TLS |
| `config/compliance.json` | GDPR/WCAG audits, client-facing reports | Accessibility, privacy, cookies, SSL/TLS |
| `config/full.json` | Complete site health check | All modules |

```bash
node dist/index.js                        # full audit (default)
node dist/index.js config/sdet.json
node dist/index.js config/compliance.json
node dist/index.js config/full.json
```

## Audit modules

| Module | Prefix | What it checks |
|---|---|---|
| Accessibility | `ACC` | WCAG violations via axe-core (configurable version + level) |
| Privacy | `PRI` | Cookie consent banner, privacy policy, CCPA "Do Not Sell" link, GPC declaration |
| Cookies | `COO` | Secure flag, HttpOnly flag, SameSite attribute, third-party cookies, expiry |
| Security Headers | `SEC` | CSP, HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, mixed content |
| SSL/TLS | `SSL` | Certificate expiry, TLS version, HTTPS redirect |
| Broken Links | `LNK` | Internal links returning 4xx/5xx |

---

## Output formats

Markdown, HTML, and JSON are generated by default. PDF is opt-in — set `"pdf": true` in `output.formats`. Files are named `{domain}-{timestamp}.{ext}`.

| Format | Purpose |
|---|---|
| `.md` | Scannable markdown, great for AI tools and code review |
| `.html` | Colour-coded, self-contained — best for sharing with stakeholders |
| `.json` | Machine-readable output with scores, for CI/CD tooling |
| `.pdf` | Opt-in — useful for formal client deliverables |

---

## Scoring

Each module receives a score (0–100%) and letter grade based on the ratio of passing checks to total checks.

| Grade | Score |
|---|---|
| A | ≥ 90% |
| B | ≥ 75% |
| C | ≥ 60% |
| D | < 60% |

An overall score is the average across all enabled modules.

---

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Audit passed — no issues found |
| `1` | Issues found |
| `2` | Tool error (invalid config, network failure, etc.) |

## GitHub Actions example

```yaml
name: Site Audit
on: [push, pull_request]

jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20' }
      - run: npm ci && npx playwright install chromium
      - run: node dist/index.js config/sdet.json
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: audit-report
          path: reports/
```

## Configuration reference

```json
{
  "modules": {
    "accessibility": {
      "enabled": true,
      "standard": "wcag",    // "wcag" | "en301549"
      "wcag": { 
        "version": "2.2",    // "2.0"|"2.1"|"2.2"
        "level": "AA"        // "A"|"AA"|"AAA"
      } 
    },
    "privacy": { 
      "enabled": true 
    },
    "cookies": { 
      "enabled": true 
    },
    "securityHeaders": { 
      "enabled": true 
    },
    "ssl": { 
      "enabled": true 
    },
    "brokenLinks": {
      "enabled": true,
      "includeExternal": false  // true to also check outgoing external links
    }
  },
  "output": {
    "formats": {
      "markdown": true,
      "html": true,
      "pdf": false,
      "json": true
    }
  },
  "compareLastRun": false,  // true to diff against .last-run.json and flag new violations
  "maxIssuesPerRule": 5,    // max violations shown per rule in reports; 0 = unlimited
  "keepRunsForDays": 0,     // auto-delete report folders older than N days; 0 = keep all
  "suppress": [
    // Suppress known accepted issues by rule + URL pattern.
    // { "rule": "color-contrast", "url": "*" }
  ],
  "crawl": {
    "depth": 1,       // 1 = target page only; 2 = target + all linked pages
    "maxPages": 10    // hard cap on pages crawled; 0 = unlimited
  },
  "urls": [
    // One URL → crawl mode (follows links up to depth/maxPages)
    // Multiple URLs → list mode (audits exactly those pages)
    "https://example.com"
  ]
}
```
